# Uber Data Analytics Project

## 📊 Project Overview
This project analyzes Uber trip data using Google Sheets / Excel.  
The dataset contains 50,000+ trip records with details such as city, distance, fare amount, payment method, trip status, and more.

## 🎯 Objectives
- Calculate total trips completed
- Find total revenue from completed trips
- Analyze city-wise performance (Seattle, New York, San Francisco, Boston, etc.)
- Calculate average fare and average distance
- Filter trips by payment method (UPI, Wallet, Cash, Card)
- Analyze trips based on distance and fare categories

## 📁 Dataset Columns
| Column                | Description                          |
|-----------------------|--------------------------------------|
| trip_id               | Unique trip identifier               |
| city                  | City of the trip                     |
| distance_km           | Distance traveled in kilometers      |
| fare_amount           | Fare charged for the trip            |
| status                | Trip status (Completed, Cancelled, No-Show) |
| payment_method        | Payment mode (UPI, Wallet, Cash, Card) |
| fare_category         | Low / Medium / High                  |
| ride_type             | Normal Ride / Premium Ride           |
| promo_eligible        | Whether promo was applied            |
